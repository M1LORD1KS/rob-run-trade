ROB RUN TRADE — frontend prototype

Состав:
- index.html — интерфейс маркетплейса
- styles.css — адаптивный тёмный дизайн
- script.js — демонстрационные взаимодействия

Запуск:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для публикации загрузите содержимое папки в Netlify Drop или подключите репозиторий к Netlify.

ВАЖНО: это только frontend-прототип.
- Вход/регистрация — локальная демонстрация в localStorage, не настоящая безопасная авторизация.
- Объявления и предложения сохраняются только в браузере текущего устройства.
- Другие пользователи их не увидят.
- Нет backend, базы данных, чата, модерации и реальной передачи игровых предметов.
- Для production нужны сервер и БД, например Supabase/Firebase или собственный backend; защищённая авторизация; правила доступа; антиспам и модерация.
- Никогда не запрашивайте пароль Roblox, cookie или коды 2FA.
- Предметы/цены в карточках вымышлены, замените их проверенными данными.
- ROB RUN TRADE — неофициальный фанатский проект, не связанный с Roblox или разработчиками ROB RUN.
